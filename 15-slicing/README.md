# 第 15 关：切片

## 🎯 这一关你会学到

- 切片语法 `L[start:stop:step]`
- 正向切片和反向切片
- 省略参数的含义
- 切片不会越界（和索引不同）
- 字符串切片和列表复制

## 🤔 先想一个问题

你有一条面包，想切下中间的几片。你需要告诉面包师：「从第 2 片开始切，切到第 5 片（不含）」。Python 切片就是这把刀——`L[2:5]` 从下标 2 切到 5（不含 5）。和 Go 的 `slice[low:high]` 语法几乎一样，但 Python 多了个**步长**参数，能玩出更多花样。

## 📖 看代码

```python
L = ['Michael', 'Sarah', 'Tracy', 'Bob', 'Jack']

# 基本切片
print(L[0:3])      # ['Michael', 'Sarah', 'Tracy']（前3个）
print(L[1:3])      # ['Sarah', 'Tracy']（第2到第3个）
print(L[:3])       # ['Michael', 'Sarah', 'Tracy']（省略 start = 从头开始）
print(L[-2:])      # ['Bob', 'Jack']（后2个）
print(L[:])        # ['Michael', 'Sarah', 'Tracy', 'Bob', 'Jack']（完整复制）

# 带步长
L2 = list(range(10))
print(L2[::2])     # [0, 2, 4, 6, 8]（每隔一个取）
print(L2[::-1])    # [9, 8, 7, 6, 5, 4, 3, 2, 1, 0]（反转！）

# 字符串切片
s = 'ABCDEFG'
print(s[:3])       # 'ABC'
print(s[::-1])     # 'GFEDCBA'

# 切片不越界
print(L[0:100])    # ['Michael', 'Sarah', 'Tracy', 'Bob', 'Jack']（不报错，取到末尾）

# 切片复制（浅拷贝）
copy = L[:]
copy[0] = 'Changed'
print(f"original: {L[0]}")  # original: Michael（不受影响）
```

## 🔍 师兄给你逐行拆

### `L[start:stop:step]` —— 三个参数的含义

| 参数 | 含义 | 默认值 |
|------|------|--------|
| start | 起始下标（包含） | 0 |
| stop | 结束下标（不包含） | len(L) |
| step | 步长 | 1 |

**核心规则**：左闭右开——包含 start，不包含 stop。和 Go 切片、`range()` 的规则完全一致。

---

### `L[::-1]` —— 一行反转

步长为 `-1` 表示从右往左取，效果就是**反转**。这是 Python 最优雅的反转写法，字符串、列表、元组都能用。

---

### 切片不越界 —— 和索引不同

`L[0]` 越界会报 `IndexError`，但 `L[0:100]` 不会报错，只是取到末尾为止。切片在越界时**静默截断**，这个设计让切片操作更安全。

---

### 切片复制 vs 赋值

```python
copy = L[:]     # 浅拷贝，copy 和 L 是不同的列表
ref = L         # 引用，ref 和 L 是同一个列表
```

`L[:]` 创建了一个**新列表**（浅拷贝），修改 copy 不影响 L。直接 `ref = L` 只是多了一个引用，它们指向同一个列表。

## 💡 师兄的碎碎念

- 切片操作**不会修改原列表**，而是返回一个新列表。所以切片是安全的只读操作。
- `L[::2]` 取偶数位，`L[1::2]` 取奇数位。面试常考：「一行代码判断字符串是否是回文」→ `s == s[::-1]`。
- 切片也可以用于**赋值**：`L[1:3] = [10, 20]` 会替换 L 中下标 1 和 2 的元素。
- Go 切片 `s[low:high]` 和底层数组共享内存，Python 切片是**复制**（浅拷贝），两者行为不同。

## 🎓 这一关的知识点清单

- **切片语法**：`L[start:stop:step]`，左闭右开。
- **省略参数**：`L[:3]` 从头开始，`L[2:]` 到末尾，`L[:]` 完整复制。
- **负数索引**：`L[-2:]` 从倒数第二个开始取。
- **步长**：`L[::2]` 每隔一个取，`L[::-1]` 反转。
- **不越界**：切片超出范围不报错，静默截断。
- **浅拷贝**：`L[:]` 创建新列表，和 `L` 互不影响。
