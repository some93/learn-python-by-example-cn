# 第 2 关：数据类型和变量（师兄带你学 Python）

## 🎯 这一关你会学到

- Python 的五种基本数据类型：整数、浮点数、字符串、布尔值、None
- 变量的动态类型特性——不需要声明类型，直接赋值就行
- Python 变量是「标签」而不是「盒子」
- `type()` 函数查看任意对象的类型
- 常量的约定写法

## 🤔 先想一个问题

想象你有一本活页笔记本。Go 语言的变量像是**固定格式的表格**——每个格子必须提前标好「这里只能填数字」或「这里只能填文字」，填错了编译器直接拦你。

Python 的变量像是**便利贴**——你随手写个名字贴在任何东西上面。今天贴在一个苹果上，明天撕下来贴在一本书上，完全没人管你。这就是**动态类型**的自由感。

自由的代价是什么？**运行时才发现类型错误**。Go 在编译时就告诉你「你拿字符串去做除法，想啥呢」，Python 要等到运行到那一行才会报错。

## 📖 看代码

```python
# Python 的基本数据类型和变量

# 整数：没有大小限制！
a = 100
b = -8080
c = 0xff00        # 十六进制
print(a, b, c)    # 100 -8080 65280

# 浮点数：有精度限制
d = 1.23
e = 1.23e9        # 科学计数法，1.23 × 10^9
f = 0.1 + 0.2     # 经典精度问题
print(d, e, f)    # 1.23 1230000000.0 0.30000000000000004

# 字符串：单引号或双引号都行
s1 = 'hello'
s2 = "world"
print(s1, s2)     # hello world

# 布尔值：True 和 False（注意大写）
t = True
f = False
print(t, f)       # True False
print(t and f)    # False
print(t or f)     # True
print(not t)      # False

# None：表示"什么都没有"
n = None
print(n)          # None

# 变量赋值：动态类型，不需要声明
x = 10          # x 现在是 int
print(type(x))    # <class 'int'>
x = "hello"     # x 现在变成了 str，完全合法！
print(type(x))    # <class 'str'>

# 多重赋值
a, b, c = 1, 2, 3
print(a, b, c)    # 1 2 3

# 交换变量值（Python 的优雅写法）
a, b = b, a
print(a, b)     # 2, 1

# 常量：约定用全大写，但 Python 没有真正的常量机制
PI = 3.14159265
MAX_SIZE = 100
print(PI, MAX_SIZE)  # 3.14159265 100

# type() 查看类型
print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>
print(type(None))       # <class 'NoneType'>
```

## 🔍 师兄给你逐行拆

### 整数（int）—— 想多大就多大

```python
a = 100
b = -8080
c = 0xff00        # 十六进制
```

**这行在干嘛？**

声明三个整数变量。`0xff00` 是十六进制写法，等于十进制的 65280。

**为什么 Python 的整数特殊？**

Python 的整数**没有大小限制**！不像 Go 的 `int64` 最大只能到 `9223372036854775807`，Python 可以算到天文数字：

```python
>>> 2 ** 100
1267650600228229401496703205376
```

这个数字在 Go 里直接溢出，Python 轻松拿捏。原因是 Python 底层自动用「大整数」实现，内存够用就能算。

**容易踩的坑**

Python 3 里整数除法 `/` 返回浮点数：`10 / 3` 得到 `3.3333...`。想要整除用 `//`：`10 // 3` 得到 `3`。这和 Go 不同——Go 里两个整数相除直接是整除。

---

### 浮点数（float）—— 小数点的小心思

```python
d = 1.23
e = 1.23e9        # 科学计数法
f = 0.1 + 0.2     # 经典精度问题
```

**这行在干嘛？**

声明浮点数。`1.23e9` 是科学计数法，等于 `1230000000.0`。

**经典坑：0.1 + 0.2 ≠ 0.3**

```python
>>> 0.1 + 0.2
0.30000000000000004
```

这不是 Python 的 bug，是所有使用 IEEE 754 浮点数标准的语言都有的问题（Go、Java、JavaScript 都一样）。如果需要精确计算，用 `decimal` 模块。

---

### 变量的动态类型 —— 自由的代价

```python
x = 10          # x 现在是 int
x = "hello"     # x 现在变成了 str
```

**这行在干嘛？**

同一个变量 `x`，先赋值为整数 10，再赋值为字符串 "hello"。在 Python 里**完全合法**。

**为什么这么写？**

Python 是**动态类型语言**——变量本身没有类型，它只是一个「名字标签」，贴在哪个对象上就指向哪个对象。Go 是**静态类型语言**——变量一旦声明了类型就不能改。

**生活类比**

Go 的变量像是**专用停车位**——写着「小轿车专用」，你开辆卡车来就不让停。Python 的变量像是**共享停车位**——今天停轿车，明天停摩托，后天停自行车，随便。

**容易踩的坑**

自由带来风险：你可能在第 100 行把一个本该是数字的变量不小心赋值成了字符串，到第 200 行拿它做数学运算时才报错。这就是为什么大型 Python 项目会用**类型注解（Type Hints）**来弥补这个问题。

---

### `type()` —— 你是谁？

```python
print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type(True))       # <class 'bool'>
print(type(None))       # <class 'NoneType'>
```

**这行在干嘛？**

`type()` 是内置函数，返回对象的类型。调试时特别好用——当你不确定一个变量现在是什么类型时，`print(type(x))` 一下就知道了。

**冷知识**：`bool` 是 `int` 的子类！`True` 等于 `1`，`False` 等于 `0`。所以 `True + True` 等于 `2`，虽然你永远不该这么写。

---

### 多重赋值和变量交换

```python
a, b, c = 1, 2, 3
a, b = b, a     # 交换
```

**这行在干嘛？**

Python 支持一行同时给多个变量赋值。更酷的是，交换两个变量的值**不需要临时变量**——`a, b = b, a` 一行搞定。

在 Go 里交换变量要么写三行（用临时变量），要么用 `a, b = b, a`（Go 也支持这个语法）。Python 的这个写法底层是先把右边打包成一个 tuple `(b, a)`，再解包赋值给左边。

---

### 常量 —— 君子协定

```python
PI = 3.14159265
MAX_SIZE = 100
```

**这行在干嘛？**

Python **没有真正的常量机制**（不像 Go 有 `const` 关键字）。全大写变量名只是一种**约定**，告诉别人「请不要修改这个值」。但如果有人非要写 `PI = 3`，Python 不会阻止——这就是动态语言的「信任文化」。

## 💡 师兄的碎碎念

- Python 的整数没有溢出问题，算多大都行。但浮点数和其他语言一样有精度限制，需要精确计算时用 `decimal.Decimal`。
- `//` 是整除，`/` 是真除法，`%` 是取余，`**` 是幂运算（`2 ** 10 = 1024`）。Go 没有 `**` 运算符，得用 `math.Pow()`。
- Python 中一切皆对象——`42` 不是一个「原始值」，它是一个 `int` 对象，有自己的方法。你可以 `(42).bit_length()` 看它占几个二进制位。
- 变量命名用**蛇形命名法**（`max_size`），不用驼峰（`maxSize`）。这是 PEP 8 规范，和 Go 的驼峰习惯不同。

## 🎓 这一关的知识点清单

- **int**：整数，无大小限制，支持十六进制 `0x`、八进制 `0o`、二进制 `0b`。
- **float**：浮点数，有精度问题，支持科学计数法 `1.23e9`。
- **str**：字符串，单引号双引号等价。
- **bool**：布尔值，`True`/`False`（首字母大写），是 `int` 的子类。
- **None**：空值，表示「什么都没有」，类型是 `NoneType`。
- **动态类型**：变量不需要声明类型，可以随时指向不同类型的对象。
- **type()**：内置函数，返回对象的类型。
- **常量约定**：全大写命名表示常量，但 Python 无法强制不可修改。
