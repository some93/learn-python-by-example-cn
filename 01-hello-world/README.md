# 第 1 关：Hello World（师兄带你学 Python）

## 🎯 这一关你会学到

这一关你会写出人生第一个 Python 程序，搞清楚 Python 程序从「敲代码」到「看到结果」的完整流程。你会理解 `print()` 函数的基本用法、交互模式和脚本模式的区别，以及初学者最容易踩的中文标点坑。

## 🤔 先想一个问题

想象你去一家新奶茶店打工第一天，店长说：「你先喊一声『欢迎光临』，让我听听你嗓门够不够大。」——这就是你和这家店的第一次交互：输入一个指令（张嘴喊），得到一个输出（声音）。

Python 程序也是这个逻辑。你的第一个任务就是让计算机「开口说话」——在屏幕上打印一行文字。别小看这一步，它验证了你的 Python 环境能跑起来、你的代码语法没问题，一切就绪。

所谓「Hello World」，是程序界约定俗成的「第一声问候」——从 1978 年 C 语言教材开始，几乎所有编程语言的教程都用它作为开场白。今天轮到 Python 了。

## 📖 看代码

```python
# 我们的第一个程序将打印传说中的 "hello world"

print("hello, world")
```

## 🔍 师兄给你逐行拆

### `print("hello, world")` —— 整个程序就这一行

**这行在干嘛？**

`print()` 是 Python 的内置函数，作用是把括号里的内容**打印到终端**，并且默认在末尾加一个换行符。这里我们传入了一个字符串 `"hello, world"`，所以终端会显示 `hello, world` 然后换行。

**为什么这么写？**

和 Go/Java/C 不同，Python **不需要**任何「骨架代码」。不需要 `package main`、不需要 `import`、不需要 `func main()` 或 `public static void main`——你想让程序干嘛，直接写就行。这就是 Python 被称为「优雅」的原因之一：**最少的仪式感，最快上手**。

Go 的 Hello World 需要 5 行代码（package + import + func main + fmt.Println + 大括号），而 Python 只需要 1 行。这不是说 Python 更好，而是两种语言的设计哲学不同：Go 追求显式和严谨，Python 追求简洁和直觉。

**生活类比**

Go 写 Hello World 就像去银行办事——先取号、再排队、再到窗口、再填表、最后才办业务。Python 写 Hello World 就像路边摊买串——指一下说「来一串」，直接给你烤上，没有中间商赚差价。

**容易踩的坑**

新手最最最常见的错误：**用了中文标点**。

```python
# ❌ 错误：中文括号
print（"hello"）
# SyntaxError: invalid character '（' (U+FF08)

# ❌ 错误：中文引号
print("hello")
# SyntaxError: invalid character '"' (U+201C)

# ✅ 正确：全英文标点
print("hello")
```

Python 代码里所有标点符号必须是**英文半角**的。括号、引号、冒号、逗号——全部用英文版。建议把输入法切成英文模式再写代码，养成习惯后就不会踩这个坑了。

### 关于 `print()` 的更多姿势

`print()` 远不止打印一个字符串这么简单，这里先预告几招：

```python
# 打印数字，不用加引号
print(100 + 200)    # 输出: 300

# 打印多个值，用逗号分隔，输出时自动加空格
print("1 + 2 =", 1 + 2)    # 输出: 1 + 2 = 3

# 字符串可以用单引号或双引号，效果一样
print('hello')      # 输出: hello
print("hello")      # 输出: hello
```

单引号和双引号在 Python 里**完全等价**（Go 里单引号是 rune，双引号是 string，不能混用）。Python 这么设计是为了方便——字符串里有双引号时用单引号包，有单引号时用双引号包，不用转义：

```python
print("I'm learning Python")    # 字符串含单引号，用双引号包
print('He said "hello"')        # 字符串含双引号，用单引号包
```

### 交互模式 vs 脚本模式

Python 有两种运行方式，搞清楚它们的区别很重要：

**交互模式（REPL）**：在终端输入 `python`，进入 `>>>` 提示符，输入一行执行一行，适合快速试验。

```
>>> 100 + 200
300
>>> print("hello")
hello
```

**脚本模式**：把代码写在 `.py` 文件里，用 `python 文件名.py` 一次性执行整个文件。这才是写「正经程序」的方式。

**关键区别**：交互模式会自动显示每个表达式的值（你输入 `100 + 200`，它直接显示 `300`）；脚本模式不会，你必须用 `print()` 才能看到输出。

```python
# 脚本模式下，这行什么都不会输出！
100 + 200

# 必须这样写才能看到结果
print(100 + 200)
```

类比一下：交互模式像和朋友面对面聊天——你说一句，对方立刻回一句。脚本模式像写信——你写完整封信寄出去，对方看完整封信再回复，中间不会插嘴。

## 🏃 跑一下试试

```bash
# 用脚本模式运行
$ python hello-world.py
hello, world
```

一行输出，干净利落。你的第一个 Python 程序跑起来了！

## 💡 师兄的碎碎念

- Python 文件以 `.py` 结尾，文件名建议用小写加连字符（`hello-world.py`）或下划线（`hello_world.py`），别用空格和中文，否则在命令行里打路径会很痛苦。
- `print()` 默认在末尾加换行。如果不想换行，可以加参数 `end=""`：`print("hello", end="")`。
- Python 不需要分号结尾。每写完一行直接换行就是下一条语句。你硬要加分号也不会报错，但同事会用异样的眼神看你——「这人是不是 Java 转过来的？」
- 和 Go 不同，Python **不需要编译**。`python hello-world.py` 直接解释执行，省去了编译步骤。代价是运行速度比 Go 慢，但开发速度快得多。

## 🎓 这一关的知识点清单

- **print() 函数**：Python 内置函数，把内容打印到标准输出并自动换行。是你在 Python 里用得最多的调试工具。
- **字符串字面量**：用单引号 `'...'` 或双引号 `"..."` 包裹的文本，两者完全等价。
- **交互模式 vs 脚本模式**：交互模式（`>>>`）适合试验，脚本模式（`.py` 文件）适合写正经程序。脚本模式下必须用 `print()` 才能看到输出。
- **中文标点陷阱**：Python 代码必须使用英文半角标点，中文括号和引号会导致 `SyntaxError`。
- **无需骨架代码**：Python 不需要 main 函数、不需要包声明、不需要 import（除非用到外部模块），一行 `print()` 就是一个完整程序。
