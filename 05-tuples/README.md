# 第 5 关：元组 Tuple（师兄带你学 Python）

## 🎯 这一关你会学到

- 元组（tuple）的创建和使用
- 元组与列表的核心区别：**不可变**
- 单元素元组的逗号陷阱 `(1,)` vs `(1)`
- 元组的「可变」假象：内含 list 时的行为
- 什么时候该用 tuple 而不是 list

## 🤔 先想一个问题

列表（list）像是白板——随时可以擦写修改。元组（tuple）像是**刻在石碑上的文字**——一旦刻好就不能改了。为什么要有这种「不能改」的数据结构？因为**不可变意味着安全**。当你把一组数据传给别人，又不希望他们偷偷改掉，tuple 就是最好的选择。

## 📖 看代码

```python
# 创建元组
t = (1, 2, 3)
print(t)           # (1, 2, 3)
print(t[0])       # 1
print(t[-1])      # 3
print(len(t))     # 3

# 元组不可修改！
# t[0] = 10       # TypeError

# 单元素 tuple 必须加逗号！
t1 = (1,)         # 这是 tuple
t2 = (1)          # 这是整数 1！
print(type(t1))   # <class 'tuple'>
print(type(t2))   # <class 'int'>

# 元组的"可变"陷阱
t3 = ('a', 'b', ['X', 'Y'])
print("修改前:", t3)  # 修改前: ('a', 'b', ['X', 'Y'])
t3[2][0] = 'M'
t3[2][1] = 'N'
print("修改后:", t3)  # 修改后: ('a', 'b', ['M', 'N'])

# 解包
x, y, z = (10, 20, 30)
print(x, y, z)    # 10 20 30

# tuple 可以作为 dict 的 key
d = {(1, 2): "point A", (3, 4): "point B"}
print(d[(1, 2)])  # point A
```

## 🔍 师兄给你逐行拆

### 单元素 tuple 的逗号陷阱 —— 最经典的坑

```python
t1 = (1,)    # tuple
t2 = (1)     # int！
```

**为什么必须加逗号？**

因为 Python 里小括号 `()` 也用于数学运算的分组。`(1)` 被 Python 理解为「数学运算里的括号包了个 1」，结果就是整数 1。只有加了逗号 `(1,)`，Python 才知道你要创建一个元组。

**生活类比**

就像你说「我要一份（炒饭）」，这只是在强调「炒饭」。但你说「我要一份（炒饭，）」——等等你加了个逗号——那就是在列举一份清单，只不过清单只有一项。逗号是「这是清单」的信号。

---

### 元组的"可变"假象 —— 面试必考题

```python
t3 = ('a', 'b', ['X', 'Y'])
t3[2][0] = 'M'    # 居然没报错？
```

**这到底怎么回事？**

tuple 说的「不可变」是指 **tuple 中每个位置指向的对象不能变**——`t3[0]` 永远指向字符串 `'a'`，`t3[2]` 永远指向那个 list。但 list 本身是可变的！所以你修改了 list 内部的元素，tuple 的引用并没有变，Python 不会报错。

**生活类比**

tuple 像是**固定的衣架**——你不能增减衣架的数量，也不能把衣架移走。但如果某个衣架上挂的是一个**口袋（list）**，你可以往口袋里塞东西、拿东西。衣架没变，变的是口袋的内容。

---

### 为什么用 tuple 而不是 list？

1. **安全性**：不可变意味着不会被意外修改
2. **性能**：tuple 比 list 略快，占用内存更小
3. **可哈希**：tuple 可以作为 dict 的 key 和 set 的元素，list 不行

## 💡 师兄的碎碎念

- 函数返回多个值时，Python 其实就是返回了一个 tuple：`return a, b` 等价于 `return (a, b)`。
- 解包（unpacking）不仅 tuple 能用，list 也能用：`a, b, c = [1, 2, 3]`。
- `*` 解包可以收集剩余元素：`a, *rest = (1, 2, 3, 4)` → `a=1, rest=[2, 3, 4]`。
- 在不需要修改的场景下，优先用 tuple。面试官问「tuple 和 list 有什么区别」，答出**不可变、可哈希、性能更好**三点就够了。

## 🎓 这一关的知识点清单

- **创建**：`(elem1, elem2, ...)`，空元组 `()`，单元素 `(elem,)` 必须加逗号。
- **不可变**：不能增、删、改元素。但如果元素本身是可变对象（如 list），其内部可以修改。
- **索引**：和 list 完全一样，`t[0]`、`t[-1]`。
- **解包**：`x, y, z = (1, 2, 3)` 将 tuple 元素分别赋给多个变量。
- **可哈希**：tuple 可以作为 dict 的 key，list 不行。
