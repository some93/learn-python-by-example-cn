# 第 10 关：集合 Set（师兄带你学 Python）

## 🎯 这一关你会学到

- 集合（set）的创建和基本操作
- 集合的核心特性：**无序、不重复**
- 集合运算：交集、并集、差集
- set 用于去重的经典用法

## 🤔 先想一个问题

你手里有一堆优惠券，有些是重复的。你想快速去掉重复的，留下不同的优惠券。一张一张比对太慢了——直接全部倒进一个**只收不同券**的篮子里，重复的自动被拒绝。这就是集合的天然去重能力。

## 📖 看代码

```python
# 创建 set——自动去重
s = {1, 2, 3, 1, 2}
print(s)                  # {1, 2, 3}

# 添加和删除
s.add(4)
s.remove(2)
print(s)                  # {1, 3, 4}

# 集合运算
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
print(a & b)     # 交集: {3, 4}
print(a | b)     # 并集: {1, 2, 3, 4, 5, 6}
print(a - b)     # 差集: {1, 2}
print(a ^ b)     # 对称差集: {1, 2, 5, 6}

# 去重经典用法
lst = [1, 1, 2, 2, 3, 3, 4]
unique = list(set(lst))
print(unique)

# in 判断
print(3 in a)    # True
```

## 🔍 师兄给你逐行拆

### 集合运算 —— 数学课本里的交并差

```python
a & b    # 交集：两个集合都有的
a | b    # 并集：两个集合所有的
a - b    # 差集：a 有 b 没有的
a ^ b    # 对称差集：不同时在两个集合中的
```

这四个运算符和数学里的集合运算完全一致。在实际开发中，**交集**常用来找「两个用户列表的共同用户」，**差集**常用来找「新增用户」。

---

### 去重 —— set 的杀手级应用

```python
unique = list(set([1, 1, 2, 2, 3]))
```

一行代码去重。但注意：**set 是无序的**，所以去重后元素顺序可能和原来不同。如果要保持原顺序去重，可以用 `dict.fromkeys(lst)`。

## 💡 师兄的碎碎念

- **空集合必须用 `set()`**，不能用 `{}`——`{}` 创建的是空字典！这是新手常踩的坑。
- `discard(elem)` 和 `remove(elem)` 都能删元素，区别是元素不存在时 `remove` 报错，`discard` 静默忽略。
- set 底层也是哈希表，所以 `in` 判断是 O(1)，比 list 的 O(n) 快得多。大量元素的「是否存在」判断，一定要用 set。
- frozenset 是**不可变集合**，可以作为 dict 的 key 或 set 的元素。

## 🎓 这一关的知识点清单

- **创建**：`{elem1, elem2}`（自动去重）或 `set(list)`。空集合用 `set()`。
- **增/删**：`add()`、`remove()`（报错）、`discard()`（不报错）。
- **集合运算**：`&` 交集、`|` 并集、`-` 差集、`^` 对称差集。
- **去重**：`list(set(lst))` 一行去重（不保证顺序）。
- **元素约束**：和 dict 的 key 一样，只能放不可变类型。
